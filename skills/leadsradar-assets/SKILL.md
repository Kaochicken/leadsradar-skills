# 探栗·素材管家

创作者刷到好作品的第一反应是三件事：**存下来当选题、把素材拿走、把文案抠出来**。本技能让用户在手机上甩一个链接+一句话就完成，不用回电脑开插件。

当前状态：三大动作（存/下/取）全量可用。

## 一、何时启用

用户发来作品链接/截图，且消息中出现动作意图：

- **存**：「存选题 / 收进选题库 / 这个可以做 / 存一下」
- **下**：「下载 / 无水印 / 拿视频 / 存图」
- **取**：「提取文案 / 把文案给我 / 这个口播稿帮我弄出来 / 改写一下」

链接+动作都不明确时，先问一句要哪种（存/下/取），不要自作主张三连跑。

## 二、开工前：确认连接

同其他探栗技能：先 `leadsradar_connection_status`，未连接按 onboarding 指引引导，每 8 秒复查，最多 12 次。

## 三、三大动作流程

### 动作 1：存选题

1. `leadsradar_note_detail(url)` 拿完整数据
2. `leadsradar_save_topic(note)` 把返回的笔记对象原样传回存入选题仓库（云端入库待分拣，web 选题仓库与插件工作台均可见）；返回 topic_url 时附上选题卡链接
3. 插件返回 duplicates=1（已存在）时如实告知：「这篇已在仓库里，没重复存」
4. **返回 LOGIN_REQUIRED（存选题需要登录）**：把错误里的登录指引原话转述（电脑端插件 → 个人中心登录 / app.leadsradar.cn 配对），说明登录后说一声即可重试——不要省略指引只说「失败了」

### 动作 2：下载无水印素材

1. `leadsradar_note_detail(url)`
2. 返回数据含 `download_urls`（视频/图片直链）→ 整理成清单给用户，注明「链接有时效，尽快保存」；图片直链通常可直接点开看，视频直链点开可播放/另存
3. 未返回直链 → 降级话术见第四节

### 动作 3：提取文案

1. `leadsradar_note_detail(url)`，取正文（body_text）/已有转写（transcript）——**边界：这里拿的是页面自带的文字**（图文正文、已挂载的转写）；**视频口播逐字稿（ASR 转录）是插件端的登录+计费能力，Agent 未开窗**——用户要逐字稿而页面没有时如实说：「逐字稿转录要在插件里点「提取文案」才有（需登录），我先把页面正文和结构拆给你」
2. 按用户用途整理，默认输出三段式：

```
【文案拆解】
标题钩子（3 个变体）：① … ② … ③ …
内容结构：钩子 → 痛点 → 方案 → 行动，每段一句概括
口播全文：…（可直接照读，口语断句）
```

3. 用户说「改写」时保持原意换表达；说「仿写」时换主题套结构——先确认是改还是仿

呈现要求：三个动作的输出统一用【选题已存】【下载清单】【文案拆解】开头，让用户一眼知道拿到了什么；数字加粗；钩子变体分行列，不挤一段。

## 四、降级话术（下载未拿到直链时）

「这条的直链需要在插件里完成一次详情采集才有。回电脑后打开作品页用插件采一下，或在插件作品卡上直接下载。」

## 五、纪律

- 素材下载仅供个人学习/二创参考，不协助批量搬运他人内容
- 提取文案遵守平台原创生态：改写/仿写输出要明显区别于原文表述
- 详情采集受安全限额约束（单批 20 / 30 分钟 100）：用户一次丢来一堆链接要文案时，超过 20 条先拆批告知
